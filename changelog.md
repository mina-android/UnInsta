## [1.0.1] - 2026-10-20

### Added
- **About Developer & Application Info Modal**:
  - Added dedicated info ("i") icon button in the AppBar.
  - Interactive bottom sheet displaying application version (`v1.0.1`), offline privacy guarantee, developer attribution (`Mina Android`), and quick links to the GitHub repository and portfolio.
- **3-Layer Profile Picture Fallback System**:
  - **Layer 1 (Public Web API)**: Integrated Instagram public web profile endpoint (`api/v1/users/web_profile_info/`) with mobile headers and fast 4-second timeouts.
  - **Layer 2 (Public Proxy Mirror)**: Automated fallback to public proxy avatar endpoints (`ui-avatars.com`) when Instagram returns rate-limit or network errors.
  - **Layer 3 (Deterministic Instagram Gradient Monogram)**: 100% offline fallback featuring unique gradient color palettes derived from username hashes, subtle drop shadows, and clean letter monograms.
  - **Auto-Healing Avatar Widget**: `InstagramAvatar` widget automatically steps through layers if an image fails to load or decodes with network errors.
- **Persistent Startup Session Caching**:
  - Added full `AnalysisResult` JSON serialization (`toJson()` and `fromJson()`).
  - Saved complete analysis states to local `SharedPreferences` cache upon ZIP import.
  - Instant startup restoration: The app now automatically opens up directly to the last analyzed data without needing the user to pick or upload the ZIP again.
  - Top Cache Status Banner: Displays the account handle (`@username`), original export date, a "Cached" badge indicator, and quick actions to "New ZIP" or "Clear Data".
  - Dialog-confirmed "Clear Stored Data" action in the AppBar menu.
- **Advanced Search & Filter Chips**:
  - Added interactive filter chips for date ranges: `All Time`, `< 30 Days`, `< 6 Months`, `< 1 Year`, `> 1 Year`.
  - Added `Mutual Only` filter toggle chip when browsing the Followers or Following lists.
  - Enhanced sort controls for date duration (Newest date, Oldest date, A-Z, Z-A).
- **Comprehensive Project Documentation**:
  - Created [`structure.md`](file:///c:/Projects/UnInsta/structure.md): Comprehensive directory structure, component responsibility, isolate processing pipeline, and data schemas.
  - Created [`ai_instructions.md`](file:///c:/Projects/UnInsta/ai_instructions.md): Detailed conventions, offline-first privacy rules, coding standards, and testing guidelines for AI contributors.
  - Redesigned and rewrote [`README.md`](file:///c:/Projects/UnInsta/README.md) following standardized project documentation template with badges, quick navigation, architecture diagrams, and Meta export guide.
  - Added official [`LICENSE`](file:///c:/Projects/UnInsta/LICENSE) adopting the **GNU General Public License v3.0 (GPL-3.0)**.
  - Formalized suggested must-have features roadmap (Protected accounts whitelisting, CSV export, and in-app Meta export guide).

### Changed
- Replaced the hardcoded developer file path dependency with disk-cached session restoration.
- Upgraded `ExportHistoryService` to store all tabs (including pending requests and unfollowed users) rather than only followers/following lists.

## [1.0.0] - 2026-09-19

### Added
- Initial release of UnInsta offline Instagram export analyzer.
- ZIP extraction using `archive` package inside background `compute` isolate for high performance.
- Support for both HTML and JSON export formats generated by Meta Accounts Center.
- Metric segmentation tabs:
  - Don't Follow Back
  - Pending Follow Requests
  - Fans (Users who follow you, but you don't follow back)
  - Mutual Followers
  - Following & Followers lists
- Snapshot comparison engine tracking lost followers across consecutive exports.
- "Recently Unfollowed by Me" history tracker.
- Responsive design with toggleable Light and Dark theme modes.
- Direct Instagram profile opening via `url_launcher`.
